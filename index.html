⚙️ Cấu hình Hệ thống, GitHub API & Email Groupware

1. Kết nối GitHub Repository (Để lưu Domain trực tiếp từ Web UI)

Thông tin Token chỉ lưu cục bộ trên trình duyệt của bạn (localStorage), tuyệt đối không đẩy lên mạng. Khi bạn thêm/xóa domain, Web sẽ gọi GitHub API cập nhật file data/domains.json và tự động chạy GitHub Actions.

Tạo nhanh tại: GitHub Settings → Personal Access Tokens

2. Ngưỡng cảnh báo gia hạn & Danh sách Email nhận thông báo

3. Cấu hình Mail Server Công ty (Groupware SMTP / Gmail) trong GitHub Secrets

Để bảo mật mật khẩu Email Groupware của công ty, thông tin đăng nhập SMTP được lưu trong GitHub Repository → Settings → Secrets and variables → Actions → New repository secret:

Tên Secret Giá trị mẫu (Groupware Công ty) Giá trị mẫu (Gmail)
SMTP_HOST mail.tencongty.com (hoặc IP mail server) smtp.gmail.com
SMTP_PORT 587 (STARTTLS), 465 (SSL) hoặc 25 587
SMTP_USER alert@tencongty.com youremail@gmail.com
SMTP_PASS Mật khẩu tài khoản Groupware App Password (16 ký tự)
SMTP_FROM SSL Monitor <alert@tencongty.com> SSL Monitor <youremail@gmail.com>
SMTP_SKIP_TLS_VERIFY true (nếu mail nội bộ dùng cert tự ký) false
